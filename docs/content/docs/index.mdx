## Why This Hub Exists: The Multi-Language Dilemma

When you learn design patterns in one language (traditionally Java or C++98), you learn patterns tied to **class inheritance**. But when you try to write them in modern languages, you run into **paradigm dissonance**. What works seamlessly in an Object-Oriented language often feels forced in a functional or data-oriented language.

This documentation hub is designed specifically to help you **remember where you got stuck**, **understand the underlying language friction**, and **revise patterns in minutes** before interviews or architectural decisions. We explain the "why" behind the code, so you truly understand how the patterns adapt to different paradigms.

## Quick Shell Command: Scaffold a New Pattern

To scaffold a new pattern across all four languages in the root workspace, use the provided bash script. This will automatically set up the boilerplate so you can focus on implementation:

```bash
./create-projects.sh <PatternName>
```

| Language | Directory | Run Command | Watch / Dev Command |
| :--- | :--- | :--- | :--- |
| **Rust** | `rs/` | `cargo run` | `cargo watch -x run` |
| **JavaScript** | `js/` | `npm start` | `npm run dev` |
| **TypeScript** | `ts/` | `npm start` | `npm run dev` |
| **C++** | `cpp/` | `make run` | `make run` |
