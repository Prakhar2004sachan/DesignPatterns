## Gotcha 1 — Closures Have Unique Nameless Types

Every closure you write has a **unique, anonymous struct type** generated by the compiler.
You cannot name it. That is why generic placeholders `<F>` are mandatory for functions accepting closures.

```rust
// These two closures have DIFFERENT types, even though they look identical:
let a = || PdfDocument;
let b = || PdfDocument;
// typeof(a) ≠ typeof(b)
```

## Gotcha 2 — Stack Allocation Requires Known Size

Traits are **unsized** (`!Sized`). You cannot write:
```rust
let doc: Document = create_doc(); // doesn't compile
```
Because the compiler cannot reserve a stack slot of unknown size.
Generic `<D: Document>` makes the concrete type known at compile time → stack allocation works.

## Gotcha 3 — Passing `|| WordDocument` vs `WordDocument`

```rust
run_editor(WordDocument);    // passes the VALUE (the document)
run_editor(|| WordDocument); // passes a FACTORY (closure that creates it)
```
`||` is the zero-argument closure syntax. Without it, you are handing a document, not a recipe.

## Gotcha 4 — `enum` Dispatch vs `dyn Trait`

| | `enum` + `match` | `Box<dyn Trait>` |
|---|---|---|
| Family set | **Closed** (known at compile time) | Open (can add at runtime) |
| Heap alloc | None | Yes |
| Speed | Zero-cost | Virtual dispatch |
| Adding a variant | Breaks all `match` arms (good!) | Just add `impl` |

Use `enum` when you know all families upfront. Use `dyn` when the set is open.

## Gotcha 5 — Builder Ownership Transfer: `self` by Value vs `&mut self`

In C++ or JavaScript, builders return `*this` or `this` by reference. In Rust, you can choose between:

1. **`&mut self` (by reference)**: Requires holding a mutable variable (`let mut b = Builder::new();`).
2. **`self` (by value, consuming)**: Idiomatic for fluent chaining:

```rust
impl HttpRequestBuilder {
    pub fn method(mut self, method: Method) -> Self {
        self.method = Some(method);
        self
    }

    pub fn build(self) -> Result<HttpRequest, String> {
        let method = self.method.ok_or("method required")?;
        let url = self.url.ok_or("url required")?;
        // Consumes self: moves strings and vectors directly into product WITHOUT CLONING!
        Ok(HttpRequest { method, url, headers: self.headers })
    }
}
```

<Callout type="info">
**Ownership Advantage**: Consuming `self` by value prevents accidental use-after-build or aliased mutations, and transfers all owned heap data (Strings, Vecs) straight into the constructed object with zero allocation overhead.
</Callout>
